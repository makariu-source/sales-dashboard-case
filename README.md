# sales-dashboard-case
Портфолио кейсов по аналитике данных: Excel, дашборды, отчёты
## Кейс 1: Дашборд по продажам (2024)

Файл: `sales dashboard case.xlsx`

**Задача:** проанализировать продажи компании за 2024 год и выявить ключевые тренды.

**Что внутри:**
- Raw Data — исходные данные по заказам
- Monthly Summary — динамика продаж по месяцам
- Region Summary — продажи по регионам
- Top Products — топ-10 товаров
- Выводы — ключевые инсайты для бизнеса

**Ключевые выводы:**
- Продажи растут к концу года (сезонный всплеск, Q4)
- Один регион даёт значительно больше выручки — есть смысл усилить работу в отстающих регионах
